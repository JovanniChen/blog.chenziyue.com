### 一、引言：我们今天所说的 AI 究竟是什么？

先想想几个场景。

**场景一：你打开 ChatGPT，输入一段文字。**

> 帮我分析一下这段 Go 代码为什么会出现死锁。

ChatGPT 能够理解你的问题，阅读代码，分析 Goroutine 和 Channel 之间的关系，最后给我解决方案。

**场景二：你上传一张图片。**

AI 能够识别图片中的物体、文字、场景，甚至理解图片中不同物体之间的关系。

**场景三：你告诉 AI：**

> 帮我开发一个 Go 项目，实现用户注册、登录和 JWT 鉴权。

AI 不仅能够生成代码，还可能进一步读取项目文件、创建文件、执行命令、运行测试，甚至根据错误信息修改代码。

**场景四：你给 AI 一个复杂任务。**

> 分析我最近一个月的项目日志，找出错误最多的接口，并生成一份分析报告。

AI 可以通过工具读取日志、统计数据、分析异常，最终生成报错，这些能力看起来差别很大，但它们背后都涉及人工智能技术。

那么问题来了：

- AI 究竟是什么？
- AI 是怎么产生的？
- 为什么计算机能够理解人类语言？
- 为什么模型能够编写代码？
- 为什么 AI 有时候会犯错？
- ChatGPT 和传统软件到底有什么区别？

要理解这些问题，我们需要从人工智能的起源开始。

### 二、什么是人工智能(Artificial Intelligence)？

人工智能，应为叫做：Artificail Intelligence，简称 AI。

简单来说：

> 人工智能就是研究如何让计算机具备某些通常需要人类智能才能完成的能力的一门技术领域。

例如：

| 人类具备的能力 | AI 对应的技术应用  |
| :------------: | :----------------: |
|   观察和识别   | 图像识别、目标检测 |
|    听懂语言    |      语音识别      |
|    理解文字    |    自然语言处理    |
|    学习知识    |      机器学习      |
|    进行推理    |      推理模型      |
|    制定计划    |        AI A        |
|    生成内容    |     生成式 AI      |
|   与环境交互   |  机器人、自动驾驶  |

这里有一个非常重要的认识：

**人工智能并不等于大语言模型，大语言模型只是人工智能领域中的一个分支。**

例如：

- 人脸识别系统属于 AI
- 自动驾驶系统属于 AI
- 推荐算法属于 AI
- AlphaGo 属于 AI
- ChatGPT 也属于 AI

它们采用的技术可能完全不同。

#### 2.1 AI 是否真的像人一样思考？

这是一个值得深入思考的问题，假设你问 ChatGPT：

> 1 + 1 等于多少？

它回答：

> 2。

你可能觉得它像人一样理解了数学问题，但计算机内部究竟发生了什么？传统计算机程序可能直接执行：

```go
func Add(a, b int) int {
    return a + b
}
```

而大语言模型通常不是通过执行这段加法程序来回答问题的，而是通过学习大量数据，利用神经网络中的参数计算下一个 Token 的概率，再逐步生成回答，这两种方式有本质区别。

|                  传统程序                  |            大语言模型            |
| :----------------------------------------: | :------------------------------: |
|             开发者明确编写规则             |     通过训练学习数据中的规律     |
|             执行预先设计的逻辑             |         根据输入计算输出         |
|              行为通常比较确定              |        输出可能具有随机性        |
| 不会自行从数据中学习，除非额外设计学习机制 |       参数可以通过训练更新       |
|             适合确定性业务逻辑             | 适合语言理解、生成和复杂模式处理 |

当然，现代 AI 系统有可以调用传统程序，例如计算器、数据库和搜索引擎，这正是后面学习 Function Calling 和 Agent 时需要理解的基础。

#### 2.2 人工智能一定要像人一样思考吗？

不一定。

例如，你使用的电商推荐系统，它可能根据你的浏览记录、购买记录、商品特征等信息，计算哪些商品最可能符合你的兴趣，它不需要像人类一样理解商品，也不需要拥有人类的意识，只要它能够有效完成预测和推荐任务，就可以属于人工智能应用。

因此，我们学习 AI 时，应该把两个概念分开：

- 智能行为：系统能够完成某些复杂的智能任务。
- 人类意识：是否具有主观体验、自我意识等。

目前的大语言模型能够表现出很多复杂的智能行为，但这并不能证明它们拥有与人类相同的意识。
